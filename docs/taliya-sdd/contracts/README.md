# Contratos propostos, não payloads homologados
`tools.json` descreve as cinco funções; `reply.schema.json` limita a resposta pública. A API e a conta reais precisam aceitar a combinação na spec 016. Não supor suporte a todos os formatos JSON Schema do validador local.

`events.catalog.v3.json` é a lista canônica de 43 nomes propostos. `event.envelope.schema.json` usa exatamente essa lista e `event_version` inteiro. Mapear os eventos legados na 021 antes de captar; o catálogo anterior é histórico, não um segundo produtor.

`material.schema.json` define um item. `materials.catalog.json` é um wrapper com `assets` vazio enquanto não existem arquivos aprovados nesta entrega. Direitos e URLs não são inventados; a regra de publicação é server-side. Não publicar um material apenas porque passou no schema.

Nenhum JSON aqui cria banco, agente, vídeo, link de checkout ou evento real.
