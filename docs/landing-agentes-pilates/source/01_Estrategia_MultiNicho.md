## Produto

Agentes Pilates é a primeira landing de um sistema de páginas por nicho para vender acesso antecipado a uma plataforma de agentes de IA operacionais.

O produto **não** deve ser posicionado como CRM, software de agenda, chatbot, automação genérica ou consultoria.

O produto deve ser percebido como um **time invisível de agentes operacionais** que acompanha a rotina, identifica pendências e ajuda a equipe a agir.

## Mensagem central

> Você cuida dos alunos. Seus agentes cuidam do resto.

## Headline final de Pilates

> Reduza faltas, organize reposições e renove planos com agentes de IA para Pilates.

## Promessa de valor

A landing deve vender resultado prático:

- menos faltas sem ação;
- reposições mais organizadas;
- planos renovados no tempo certo;
- mensalidades menos esquecidas;
- alunos inativos chamados de volta;
- interessados que não esfriam;
- histórico/evolução do aluno organizado;
- dono com clareza sobre onde agir primeiro.

## Estratégia multi-nicho

A primeira página é `/pilates`, mas o motor deve permitir novas páginas específicas:

- `/fisioterapia`
- `/estetica`
- `/personal`

Cada página deve parecer feita para o nicho. A separação entre agentes core, funcionalidades comuns e funcionalidades específicas é interna e não deve aparecer para o visitante.

## Linguagem

Usar linguagem simples para donos de studio.

Evitar:

- lead
- follow-up
- ticket médio
- ROI
- dashboard
- workflow
- founder
- beta

Usar:

- interessado
- próximo contato
- chamar de volta
- mensalidade média por aluno
- dinheiro recuperável
- painel
- fluxo
- acesso antecipado
- agente sob medida
