# Metricas de sucesso do produto - PT-BR

> Status: Rodada 0 v0.1. Este documento define quais numeros mostram valor real para o gestor do studio.

## Regra central

Metricas devem provar operacao melhor, nao apenas uso de tela ou volume de IA.

## Metricas principais para o gestor

| Metrica | Por que importa |
| --- | --- |
| Faltas/no-show reduzidos | Impacta ocupacao e receita. |
| Reposicoes resolvidas | Reduz atrito e trabalho manual. |
| Ocupacao de turmas | Mostra capacidade aproveitada. |
| Vagas recuperadas | Mostra dinheiro recuperavel. |
| Interessados convertidos | Mostra crescimento. |
| Experimentais comparecidos | Mostra eficiencia comercial. |
| Inadimplencia reduzida | Mostra saude financeira. |
| Planos renovados | Mostra receita recorrente. |
| Alunos em risco recuperados | Mostra retencao. |
| Tempo de resposta | Mostra atendimento melhor. |
| Tarefas fechadas no prazo | Mostra operacao sob controle. |
| Aprovacoes pendentes | Mostra gargalo decisorio. |
| Incidentes de agente | Mostra confiabilidade. |
| Economia de tempo | Mostra valor dos agentes. |
| Custo/cota por resolucao | Mostra eficiencia. |

## Metricas por area

| Area | Indicadores |
| --- | --- |
| Hoje | pendencias abertas, urgentes, resolvidas, atrasadas. |
| Inbox | conversas novas, aguardando humano, tempo ate resposta, opt-outs. |
| Agenda | ocupacao, vagas abertas, chamada pendente, faltas, reposicoes. |
| Vendas | interessados, experimentais, conversao, origem, sem vaga. |
| Financeiro | atrasado, recuperado, promessas, comprovantes, excecoes. |
| Retencao | risco alto, inativos, cancelamentos evitados, reativacoes. |
| Agentes | resolucao, aprovacao, erro, cota, economia estimada. |
| Suporte | grants ativos, incidentes, tempo de resolucao. |

## Metricas para Taliya

| Metrica | Uso |
| --- | --- |
| Ativacao concluida | Saude de onboarding. |
| Tempo ate primeiro valor | Queda entre compra e uso real. |
| Agentes ativados por plano | Entitlement vs adocao. |
| Cota usada por plano | Pricing e economia. |
| Fluxos bloqueados | Gaps de dados/produto. |
| Incidentes por fluxo | Qualidade dos agentes. |
| Upgrade/downgrade | Valor percebido. |
| Churn de studio | Retencao SaaS. |

## Onde aparecem

- Hoje: resumo acionavel;
- Dinheiro na Mesa: oportunidades;
- Relatorios: analise completa;
- Uso/cotas: custo e economia;
- Agentes: qualidade;
- Mobile: apenas resumo e alertas.

## Aceite

Toda area funcional deve responder:

- qual metrica mostra valor;
- qual objeto alimenta a metrica;
- se a metrica e operacional, financeira, comercial, retencao ou confiabilidade;
- onde o gestor ve;
- qual acao pode tomar a partir dela.
