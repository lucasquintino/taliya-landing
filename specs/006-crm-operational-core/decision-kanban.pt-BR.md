## Aceito Como Baseline Candidato

| Item | Decisao |
| --- | --- |
| Forma do produto | CRM operacional para Pilates com agentes integrados. |
| Onde os agentes aparecem | CRM web, app mobile e WhatsApp. |
| Papel do WhatsApp | Canal, nao produto inteiro. |
| Baseline de fluxos | 96 fluxos candidatos. |
| Fluxos opcionais | E14 e G13 ainda em validacao. |
| Universo de casos | 157 casos candidatos mapeados. |
| Principio de execucao | Nucleo programatico antes de IA. |
| Caminho manual | Obrigatorio para casos importantes e plano Base. |
| UX dos agentes | Botoes contextuais, assistente lateral, aprovacoes e gatilhos automaticos. |

## Itens Que Talvez Devam Ser Juntados

| Item | Possivel uniao |
| --- | --- |
| Primeira semana do novo aluno | Pode virar combinacao de onboarding, frequencia e retencao. |
| Entrada de anamnese e consentimento | Pode virar parte de historico sensivel e qualidade de dados. |
| Substituicao de professor | Pode ficar dentro de disponibilidade, agenda e avisos. |
| Marco ou celebracao do aluno | Pode ficar dentro de retencao e relacionamento. |
| Revisao periodica do aluno | Pode ficar como tarefa recorrente ligada ao historico. |
