# Rodada 2 - Classificacao dos 157 casos

> Status: proposta de decisao, nao escopo final. Esta rodada reduz o universo candidato e prepara a conversa de produto sem tirar itens do radar do MVP.

## Veredito

Os 157 casos continuam uteis como universo de revisao. A decisao desta rodada nao e remover itens, e sim controlar profundidade: nem tudo deve virar tela propria, menu principal ou agente independente.

| Decisao sugerida | Total |
| --- | ---: |
| Aceitar com profundidade enxuta | 16 |
| Aceitar como caso ou trava; validar se vira agente proprio | 2 |
| Aceitar para desenho detalhado | 136 |
| Juntar com outro caso | 3 |

## Regras usadas

- Aceitar para desenho detalhado: caso recorrente e necessario para CRM operacional completo.
- Aceitar com profundidade enxuta: precisa existir, mas pode nascer como tela simples, filtro, relatorio, exportacao, configuracao ou caso dentro de outra area.
- Juntar com outro caso: caso real, mas melhor como subtarefa, filtro, checklist ou etapa de outro fluxo.
- Aceitar como caso ou trava; validar se vira agente proprio: precisa existir no CRM, mas ainda nao deve aumentar contagem de agentes.
