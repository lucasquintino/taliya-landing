# Coverage Map - Taliya Commercial Agent Core Reset

Status: planned implementation gate. This file is not proof that the reset works yet; it is the map that prevents requirements from becoming untested intention.

Scope: only the Taliya-owned commercial agent for leads from the widget and Taliya's own WhatsApp. No `/pilates` redesign, no multi-tenant work, no client/studio WhatsApp connections, no checkout/payment, no Sales Inbox redesign, no CRM product implementation.

## How To Use This Map

- Every implementation task must link to one or more rows in this map before it closes.
- Every row must eventually have concrete artifact paths: test file, eval report, trace export, Sales Inbox projection export, approval log, or baseline evidence.
- "Planned" means the protection is specified but not implemented yet.
- "Passed" is allowed only when the evidence artifact exists and the relevant gate has actually run.
- If a future bug fix cannot be mapped here, update this map first, then add/adjust schema, context, prompt, validator, renderer, projection, eval, and implementation.
- No row may be satisfied by tactical commercial logic in `runtime/runner.py`, old TS v2 paths, templates, regex/token matching, or renderer defaults.
