# Implementation Ledger - Spec 012

Purpose: keep the Agents SDK migration from drifting during implementation.

This file must be updated after every Spec 012 task closure. A task is not complete until its row has evidence, review notes, and the next task lock.

## Global Locks

- No production code before D-012 decisions are recorded in `decision-log.md`.
- No behavior implementation without a cited binding source; follow
  `implementation-source-discipline.md` for every remaining slice.
- No paid OpenAI run without explicit user approval for that run or budget.
- No public endpoint cutover before spike, shadow mode, rollback proof, and product-owner approval.
- No `/pilates` visual/layout/copy change.
- No multi-tenant, client/studio WhatsApp, checkout, or Sales Inbox UI redesign.
- No deterministic raw-text commercial routing for price, plan, demo, diagnostic, waitlist, pain-first, source opening, objection, WhatsApp product question, or mixed intent.
- No direct SDK free-form delivery to leads.
- No SDK tool may commit commercial state during reasoning unless explicitly approved as a safe operational side effect.

## Task Closure Template

For each closed task, record:

- task id;
- scope completed;
- files changed;
- evidence path;
- tests/evals/static checks run;
- proof type: design, mocked, isolated spike, integration, shadow, or production-path;
- anti-determinism review result;
- protected-scope diff result;
- paid-call result, if any;
- open risks;
- next task lock.
